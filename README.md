# bilibili-tweaks

B站油猴脚本合集，提升直播和浏览体验。

## 脚本列表

| 脚本 | 说明 |
|------|------|
| bilibili-auto-max-quality.user.js | 自动将直播切换到最高可用清晰度 |
| bilibili-live-fullscreen.user.js | F 键浏览器全屏，G 键网页全屏 |
| bilibili-hide-adblock-tips.user.js | 隐藏「检测到广告拦截插件」提示 |

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击脚本文件，选择「Raw」查看源码
3. Tampermonkey 会自动弹出安装提示，确认安装即可

## 适用范围

- 自动最高画质：`live.bilibili.com` 直播间
- 快捷全屏：`live.bilibili.com` 直播间
- 隐藏广告拦截提示：`*.bilibili.com` 全站
